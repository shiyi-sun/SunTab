# SunTab

**本地优先的新标签页，安静、克制、只属于你。** SunTab 把浏览器新标签页换成一张壁纸、一个时钟、一条搜索框，以及你自己摆放的网站图标。没有账号，没有云同步，没有遥测，也没有远端组件商城。

版本 **0.2.10** · [English](./README.md)

## 为什么是 SunTab

大多数新标签页想做成门户。SunTab 想做一张书桌：一张安静的背景、一个时钟、一条搜索框，再加上你每天真正会点的那些网站。所有数据都留在这台电脑上；只有你主动开启必应每日壁纸，或添加自动图标读取网站页面时，才会联网。

## 功能

### 壁纸与时钟

- 五款渐变预设：玄纸、夜航（默认）、雾蓝、青瓷、初雪。
- 六款纯色预设：雾紫、深蓝、蓝灰、酒红、墨绿、纯黑，也可以自己取色。
- 支持本地图片（JPG / PNG / WebP，最大 8MB），以及可选的必应每日壁纸。上传过的图片会保留在“最近上传”里，可以随时换回或删除。
- 模糊 0–20px、遮罩 0–60%，随时调节。
- 内置浅色壁纸会自动把桌面文字、搜索框和图标名称切换为深墨色。
- 时钟支持 12 / 24 小时制、秒数、农历与节气、40–140px 字号和自定义颜色。

### 搜索

- 内置百度、必应、Google、DuckDuckGo；也可以用带 `%s` 的地址模板添加、编辑或删除搜索引擎。
- 输入域名或 IP 直接打开；输入关键词则用当前搜索引擎搜索。
- 搜索栏可直接切换引擎，搜索结果默认在新标签页打开。
- 引擎前缀：`b` / `bd` 百度、`g` Google、`bing` 必应、`ddg` DuckDuckGo，也可以直接用自定义引擎的 ID，例如 `g suntab`。
- 本地图标搜索支持名称、汉字、全拼和拼音首字母；用 `↑` / `↓` 选择，`Enter` 打开。不请求网页搜索建议。

### 图标桌面

- 图标 36–120px（默认 50px），间距、圆角、名称字号、名称颜色和网格最大宽度都可以调。
- 图标来源：自动解析站点图标（优先 SVG；其次声明的 96px 以上 PNG / WebP；再次页头品牌图，横向品牌图优先裁出独立标志，找不到独立标志时整张保存）、带底色的文字首字、上传图片、图片地址。自动位图会转成 128px WebP 存本地；没有高清图标时使用浏览器缓存的网站图标，再退到文字首字。
- 图片图标默认白底。会按图片边缘自动判断：透明背景的图案保留 80% 留白，满底图片铺满卡片；纯白图案会自动改用深色底（优先站点 theme-color），每个图标都可以改色或设为透明。
- 支持文件夹、分组、拖拽排序，以及图标 / 文件夹 / 分组 / 空白处的右键菜单。
- 拖拽时有干净的落点线，会停在指针旁的缝隙里；浅色壁纸下卡片保留 1px 描边和柔和阴影，深色壁纸只用柔和阴影。

### 桌面与分组

- 分组侧边栏可放在左侧或右侧，支持宽度、透明度和自动隐藏。
- 极简模式只保留时钟、搜索和底部引用；点击时钟即可切换。
- 底部引用可以关闭。
- 桌面任意空白处右键都会打开 SunTab 菜单：添加图标、新建文件夹、新建分组、换壁纸、设置。输入框内保留浏览器原生菜单。

### 快速添加

- 把 SunTab 固定到工具栏后，在普通网页上点击图标即可添加当前页；也可以按 `Alt+Shift+S`。
- 选择分组并保存，弹窗会自动关闭；重复网址会被识别并拦截。
- 快速添加会尝试读取当前页的站点图标：已授权站点访问时优先使用页面里已渲染的图标和页头标志，未授权时只使用浏览器缓存的网站图标，不会额外弹出站点授权。

### 设置与数据

- 设置以右侧抽屉打开，换壁纸时可以实时预览。
- 分区包括：外观、壁纸、搜索、图标、时钟、布局、侧边栏、数据、关于。
- JSON 导出 / 导入包含设置、分组、文件夹和图标图片（上传、自动抓取的 SVG 或 WebP）；壁纸原图不包含在内。
- 导入前会展示预览，并自动先下载一份当前数据备份。
- 导入只恢复新导航实际引用的上传图标，并清理不再被引用的旧图标记录。
- “恢复默认设置”会重置外观、搜索、图标、时钟、布局和侧边栏，但保留图标与分组。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `/` 或 `Ctrl+K`（macOS 为 `⌘K`） | 聚焦搜索框 |
| `↑` / `↓` | 选择本地图标结果 |
| `Enter` | 搜索、打开网址，或打开选中的图标 |
| `Esc` | 收起建议、清空焦点，或取消拖拽 |
| `Alt+Shift+S` | 打开快速添加 |
| 点击时钟 | 切换极简模式 |

## 安装

SunTab 支持 Chrome、Chromium 和 Microsoft Edge。发行版同时提供 Chrome / Chromium 包和 Edge 包，两者是同一份扩展构建。

### Chrome / Chromium

1. 从 [GitHub Releases](https://github.com/shiyi-sun/SunTab/releases) 或 [AtomGit 发行版](https://atomgit.com/shiyi-sun/SunTab/releases) 下载 `SunTab-0.2.10-chrome.zip`。
2. 解压到一个固定目录，例如 `D:\SunTab\0.2.10`。
3. 打开 `chrome://extensions`，开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压出来的 `SunTab` 文件夹。
5. 打开一个新标签页。

### Microsoft Edge

1. 从发行版下载 `SunTab-0.2.10-edge.zip`。
2. 解压到一个固定目录，例如 `D:\SunTab\0.2.10-edge`。
3. 打开 `edge://extensions`，开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压出来的 `SunTab` 文件夹。
5. 打开一个新标签页。

加载后不要移动或删除该目录。Edge 使用自己独立的扩展数据；需要迁移时，在原来的浏览器导出 JSON，再到 Edge 的“设置 → 数据”导入。

### 从源码构建

需要 Node.js 20+ 和 pnpm 11+。

```bash
pnpm install
pnpm build
```

然后把 `.output/chrome-mv3` 作为已解压扩展加载。开发时运行 `pnpm dev`，WXT 会启动一个已加载扩展的浏览器。

## 权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 在 `chrome.storage.local` 保存设置与导航 |
| `unlimitedStorage` | 在 IndexedDB 保存上传的图标和壁纸 |
| `favicon` | 在快速添加预览、自动图标兜底和旧数据中读取浏览器本地图标缓存 |
| `activeTab` | 打开快速添加时读取当前页标题与网址 |
| `scripting` | 快速添加时读取当前页已渲染的图标和页头标志；仅在点击扩展或按快捷键时生效 |
| `https://*/*`、`http://*/*`（可选） | 添加“自动”图标时读取该站点页面并下载其 SVG / 高清图标；开启必应每日后下载当天壁纸 |

站点权限只在你新建或编辑“自动”图标时询问一次，授权后对所有站点生效；快速添加不会弹出站点授权：已授权时会用当前标签页已渲染的图标和页头标志，未授权时使用浏览器缓存的网站图标。读取页面时会沿用浏览器对该站点的登录状态，以便解析登录后显示的页面。必应权限在你开启每日壁纸时询问。两者都可以在浏览器设置中随时撤销。

## 隐私

SunTab 是本地优先的。设置和导航保存在 `chrome.storage.local`，上传图片保存在 IndexedDB，首屏快照保存在 `localStorage`。没有统计、没有账号，也没有后台网络请求。

唯一会联网的情况是你主动开启必应每日壁纸，或添加自动图标读取网站页面（会沿用浏览器对该站点的登录状态）。搜索和图标链接只会导航到你选择的网站；自动图标拿不到高清图标或未授权时，使用浏览器缓存的网站图标，缓存也没有时显示文字首字。

## 使用说明

- 支持 Chrome、Chromium、Microsoft Edge（Manifest V3），不支持 Firefox。
- 界面目前为简体中文。
- JSON 备份包含上传的图标图片，但不包含壁纸图片；壁纸只留在当前设备。
- 自动图标按顺序解析：站点声明的 SVG → 声明的 96px 以上 PNG / WebP → 页头品牌图（优先裁独立标志）→ mask SVG → 浏览器缓存的网站图标 → 文字首字。SVG 保留矢量，位图转成 128px WebP；两者都保存在本机并随 JSON 备份导出。空白或纯白整图会被跳过，白色图案会自动配深色底。
- 上传壁纸和必应壁纸使用浅色文字；遇到很亮的图片，可以调高遮罩让文字更清楚。
- 浏览器重新加载后默认回到第一个分组，最后选中的分组不会单独记住。
- 不提供网页搜索建议、搜索历史、书签 / 历史导入、云同步和组件商城。
- 拼音词典在第一次本地搜索时加载；快速添加只支持 `http` / `https` 页面。
- 图标很多时网格纵向滚动，分组很多时侧边栏纵向滚动。

## 开发

```bash
pnpm compile     # 类型检查
pnpm test        # 单元测试（Vitest）
pnpm build       # 生产构建
pnpm test:e2e    # Playwright；先运行 pnpm build
```

Playwright 默认加载 `.output/chrome-mv3`。如果本机没有可用的 Chromium，可以设置 `SUNTAB_CHROME=/path/to/chrome`。用 Edge 跑同一套测试：

```bash
SUNTAB_CHROME="C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" pnpm test:e2e
```
